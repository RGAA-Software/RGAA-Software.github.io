#### 4. 工作模式
##### 4.1 直连, 此模式下只需要在两端(控制端和被控端)安装GoDesk程序即可，无需安装管理端。
![](../assets/work_directly.png)
##### 4.2 直连+中转
> 1. 首先安装管理端(GoDeskServer)，确保管理端被所有节点可访问。  
> 2. 在所有控制和被控端，都安装GoDesk程序  
> 3. 配置GoDesk程序  

![](../assets/work_relay.png)
